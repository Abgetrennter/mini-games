# 小游戏合集

个人自用游戏

## 游戏列表

- [试管倒水](./water-sort.html) — 把同色液体倒进同一支管，含巨管模式
- [箭头脱出](./arrow-flow.html) — 每条线是一笔画折线，点箭头后像蛇一样从头部滑出棋盘；四档难度 8×8 ~ 14×14，剩余空隙由单格 / 双格短线填满（密度 93% ~ 83%）
- [人数战斗](./count-battle.html) — 拖动底部小兵穿过增益门（`+N` / `×N` / `−N` / `÷N`），自动射击消灭来敌；金色雕像需要大量攻击点数，打碎后给大量增益；终点是巨额血量的 BOSS，超时会压进防线。简单 / 困难两档
