# 小游戏合集

个人自用游戏

在线玩：**<https://abgetrennter.github.io/mini-games/>**

## 游戏列表

- [试管倒水](./water-sort.html) — 把同色液体倒进同一支管，含巨管模式
- [箭头脱出](./arrow-flow.html) — 每条线是一笔画折线，点箭头后像蛇一样从头部滑出棋盘；四档难度 8×8 ~ 14×14，剩余空隙由单格 / 双格短线填满（密度 93% ~ 83%）
- [人数战斗](./count-battle.html) — 拖动底部小兵穿过增益门（`+N` / `×N` / `−N` / `÷N`），自动射击消灭来敌；金色雕像需要大量攻击点数，打碎后给大量增益；终点是巨额血量的 BOSS，超时会压进防线。简单 / 困难两档
- [泡泡龙](./bubble-shooter.html) — 拖动瞄准、三连消除，打掉支撑后整块泡泡会按重力掉落。关卡是 4 屏（简单）/ 8 屏（困难）的长条，视口顶部只剩两行时即向上滚动推进；着色会刻意让同色连成片（孤色球约 6%，平均同色块约 3.8 颗）；右侧侧栏有炸弹、火箭、彩虹、闪电四种特技球，无限使用，作用范围为**当前屏 + 半屏**（不会一发打穿整条关卡）；发射球只从视口内现存的颜色里取，并避免连续三次以上同色；底部「交换」按钮（或右键 / S 键）可交换当前球与待选球；音效由 WebAudio 现场合成，可用底部按钮开关
- [麻将连连看](./mahjong.html) — 经典堆叠麻将消除：翻开两张同色自由牌（不被压且左右至少一边空）即可消除。简单 72 张金字塔、困难 144 张龟甲（春夏秋冬 / 梅兰竹菊各自互配），每一局都用「保证可解」算法反向发牌（拆解顺序 = 一组可行解），贪心打法加上洗牌兜底通过率 100%；还提供了有限次数的提示 / 洗牌 / 撤销
- [海上求生](./sea-survival.html) — 拖动海面驾驶小船，接住漂来的木板 / 塑料 / 食物 / 淡水 / 绳索；雨天集雨器收淡水，风暴持续啃船体。可升级船体、船帆、捕鱼网、集雨器、货舱，也能紧急修理；货舱满时在升级面板丢弃物品腾出空间（丢弃物会重新漂在船边）；朝同一方向坚持航行会触发补给礁石、漂流瓶、沉船残骸、小岛等里程发现，航行满 100 海里获救。简单 / 困难两档，最佳里程存 localStorage
- [同色连线](./color-link.html) — 把棋盘上同色圆点两两连线，线路不能交叉、不能穿过他色圆点，全部接通即过关。四档难度 5×5 ~ 8×8，关卡由「哈密顿一笔画 + 随机切段 + 旋转镜像」生成（参考解随盘内嵌），每一局保证可解；拖动中往回走即逐格撤销，压过别人的线会从落点把它剪断，从线中间起笔可接管改画；提示按钮直接接通一对，全部接通后填满全盘记一次「完美」；各难度关卡进度与完美次数独立存 localStorage，音效 WebAudio 现场合成
- [解绳结](./rope-untie.html) — 圆环皮板上拉满彩绳互相缠绕：拖住一根绳拔起绳头，插进空孔、或压到别的绳头上互换位置，把交叉数降到零即过关（交叉数按实际画出的坠心曲线实时判定）。四档难度 3~6 根绳 / 8~12 孔，谜面由「凸点递归无交叉配对」的正解随机打乱而来，正解内嵌且与判定同一套几何，每一局保证可解；提示每次把一个绳头归位，关卡进度按难度独立存 localStorage，音效 WebAudio 现场合成
